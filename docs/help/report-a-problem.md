# Reporting a problem

## From anywhere

Go to **You**, then **Report a problem**. It opens a chat with us. The message already has your app version and update id. If you are offline, the report is saved and sent the next time you are online. No video is attached.

**Help & support** in the You tab opens the same chat, and Fin, our AI assistant, can answer most questions straight away.

## About one lift

On a result, tap **···**, then **Report a wrong result**. Write what looks wrong. You can tick **Attach analysis numbers (no video)** to include the lift's numbers; it is off by default and you see what is attached before you send.

## Shortcuts

- A lift that could not be analysed: tap **Get help**. The message starts with the error code and the movement.
- No cue, or a cue filmed at an angle: tap **Ask why**. The message starts with the angle and the confidence.
- A payment issue: tap **Purchase problem?** on the paywall. The message starts with your plan.

Messages about a lift also say which lift, so you only need to add what happened.
